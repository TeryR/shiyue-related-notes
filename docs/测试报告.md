## 一、测试环境与方法

- 插件核心引擎（索引、相似度、增量、持久化）为纯逻辑模块，测试脚本直接复用插件源码（`src/` 下的 `indexer.ts`、`embedder.ts`、`utils.ts`、`settings.ts`），**不依赖 Obsidian 运行时**，可完全复现
- 嵌入请求走插件同一套 `OllamaEmbeddingProvider` 代码（`POST /api/embed`，批大小 16）
- 测试库：`test/vault/`，共 **1209 篇**：

| 分组 | 数量 | 说明 |
|------|------|------|
| 中文话题库 | 72 | 12 个话题 × 6 篇（3 篇手写 + 3 篇变体），话题间词汇强内聚 |
| 干扰笔记 | 4 | 跨话题日常笔记（购物/聚会/目标/软件技巧），不参与命中率计算 |
| 英文库 | 13 | 生产力/笔记方法主题，用于验证英文效果不退化 |
| 压测库 | 1120 | 40 个话题 × 28 篇，用于 1000+ 篇性能验证 |

复现命令：
```
npm install
node test/generate-vault.cjs    # 重新生成测试库
node test/run-tests.cjs         # 运行全部测试（需本机 Ollama + bge-m3）
```

### 6. 持久化（5/5 通过）

- 索引序列化 → 恢复后：计数一致、签名一致、向量一致（余弦 > 0.9999）、推荐结果逐项一致 ✅
