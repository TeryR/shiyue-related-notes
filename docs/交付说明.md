## 二、安装步骤（3 分钟）

1. 解压 `release/shiyue-related-notes-1.0.0.zip`
2. 把里面的 `shiyue-related-notes` 文件夹复制到笔记库的 `.obsidian/plugins/` 下
3. Obsidian → 设置 → 第三方插件 → 启用「智能关联」
4. 设置 → 智能关联→ 选择提供商（Ollama 本地 / OpenAI 兼容）→ 测试连接
5. 等待状态栏索引完成

详细图文步骤见 `README.md` 与 `docs/使用指南.md`。

## 三、与英文原版的过渡

1. 中文版功能入口与原版一一对应（见 `docs/功能对照表.md`），原版用户可直接上手
2. 原版笔记中的 `smart-connections` 代码块语法兼容，无需修改
3. 原版索引数据格式不互通，切换后重新索引一次（几分钟）
4. 建议迁移完成后禁用原版，避免双份索引

## 四、已知限制（诚实声明）

- **Smart Collections（自动聚类）未包含**：原版实验性功能，后续可单独开发
- **调优反馈为会话级**：重启后重置（原版为持久调优）
- **长笔记只取前 N 字参与语义**（默认 4000，可在高级设置调整）
- **移动端未专项适配**：插件不限制平台，但本地 Ollama 模式在手机上不可用（手机无法访问电脑的 127.0.0.1）
- **真实效果依赖嵌入模型**：测试使用的 bge-m3 为推荐配置；换其他模型效果可能有差异

## 五、数据与隐私

- 设置：`.obsidian/plugins/shiyue-related-notes/data.json`
- 语义索引：`.obsidian/plugins/shiyue-related-notes/embeddings.json`
- Ollama 模式：完全离线，数据不出本机
- OpenAI 模式：仅发送笔记文本给所配置的接口（语义功能原理所需），插件无任何第三方上报
