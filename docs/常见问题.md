# 常见问题（FAQ）

## 安装与加载

**Q：解压后放哪个文件夹？**
你的笔记库根目录下的 `.obsidian/plugins/`。注意是笔记库内的 `.obsidian` 文件夹（默认隐藏），不是 Obsidian 程序安装目录。

**Q：插件列表里看不到「智能关联」？**
1. 确认文件夹名是 `shiyue-related-notes`（manifest.json 就在里面，别多套一层）
2. 确认 Obsidian 的「安全模式」已关闭：设置 → 第三方插件
3. 重启 Obsidian（完全退出再打开）

**Q：启用时报错 / 控制台红字？**
打开开发者工具（Ctrl+Shift+I）看报错信息，常见原因：
- 插件文件夹结构不对（缺 main.js 或 manifest.json）
- 版本过旧（插件要求 Obsidian 1.4.0+）

## 模型与连接

**Q：为什么「测试连接」失败？**

| 报错 | 原因 | 解决 |
|------|------|------|
| API Key 无效或已过期 | Key 错了或额度用完 | 检查 Key 与账户余额 |
| 模型不存在或接口地址有误 | 模型名不对 / 接口地址不对 | 核对模型名与 base URL |
| 请求超时 | 网络慢或代理问题 | 设置里调大「请求超时」；检查代理 |
| 网络请求失败 | 无法访问接口 | 确认网络/代理；中转地址要带 `/v1` |
| Ollama 中找不到模型 | 没拉模型 | 运行 `ollama pull bge-m3` |

**Q：Ollama 的地址是什么？**
默认 `http://127.0.0.1:11434`。如果 Ollama 装在别的机器/端口，改成对应的 `http://IP:端口`。

**Q：推荐什么嵌入模型？**
- Ollama：`bge-m3`（中文最强，上下文 8K，够用）
- OpenAI：`text-embedding-3-small`（便宜且中文效果好）；追求更高精度用 `text-embedding-3-large`（更贵）

**Q：API Key 存在哪？安全吗？**
存在 `.obsidian/plugins/shiyue-related-notes/data.json`，只在本机。输入框是密码掩码显示。注意：不要把整个笔记库分享给别人，否则 Key 会一起泄露。

## 索引

**Q：为什么状态栏一直显示「正在索引」？**
首次使用、切换模型、或导入大量新笔记时都会全量索引。1000 篇笔记在 Ollama 本地约几分钟，期间正常记笔记即可。如果长时间卡住不动，检查模型是否可用（设置 → 测试连接）。

**Q：索引出错停住了？**
常见于：API Key 失效、Ollama 模型没拉、网络断开。状态栏会变红显示「索引出错」。修复配置后，设置 → 索引管理 →「立即重建索引」。

**Q：重建索引会丢笔记吗？**
不会。索引只是每篇笔记的向量缓存，重建只是重新计算，笔记文件不受影响。

**Q：智能对话报错「the input length exceeds the context length」？**
输入内容超过了对话模型的上下文长度。常见原因：引用的相关笔记太多/太长、对话轮次太多、或模型上下文本身较小（Ollama 对话模型默认上下文不大）。
处理（按见效顺序）：
1. 设置 → 高级 → 把「对话引用笔记数」调小（2–3 即可）
2. 少提多轮连续问题，或点「新对话」重开
3. 换上下文更大的对话模型（如 qwen2.5:14b 等更长上下文的模型）
4. 新版已自动压缩引用内容（总量约 3000 字符）与对话历史（仅保留最近 6 条），正常使用不会再触发

**Q：为什么有的笔记搜不到/不推荐？**
- 在「排除的文件夹」里（设置里可以管理）
- 纯代码块、纯图片、空白笔记（没有可嵌入的文本）
- 刚新建，等几秒自动索引；修改了内容，等 1 秒自动更新

## 推荐质量

**Q：推荐结果不相关？**
1. 先确认索引完成（状态栏）
2. 调高「最低相似度」只看强相关；或调低看更多候选
3. 换更好的嵌入模型（bge-m3 / text-embedding-3-large）
4. 太短的笔记（一两行）语义信息少，推荐质量天然差
5. 用调优反馈（＋/－）逐步修正

**Q：长笔记只取前 N 字，后面的内容影响推荐吗？**
会受影响（这是设计取舍，节省额度和时间）。当前整篇参与上限默认 16000 字，长文会切成 800 字左右的语义块逐块索引；需要更多可在设置 → 高级里调大「整篇笔记参与上限」。

## 与原版的关系

**Q：和 Smart Connections 什么关系？**
功能复刻 + 全中文。核心功能（侧边栏、语义搜索、Smart View、索引、设置）一一对应；原版实验性的 Smart Collections（自动聚类分组）未包含。见[功能对照表](docs/功能对照表.md)。

**Q：能直接读原版的索引数据吗？**
不能。两边数据格式不同，切换后重新索引一次即可（几分钟）。

**Q：两个插件能同时开吗？**
能，但会重复建索引、占双倍磁盘。迁移完成后建议只留一个。

## 其他

**Q：手机上能用吗？**
插件不限制平台，但需要能访问你配置的接口（Ollama 指本机地址时手机无法访问；OpenAI 接口理论上可用）。移动端未做专门适配。

**Q：会联网上传我的笔记吗？**
选择 OpenAI 兼容接口时，笔记内容会发送给该接口用于计算向量/对话（这是语义功能的原理）；选择 Ollama 本地模型时完全离线，数据不出本机。插件本身不包含任何第三方上报代码。

**Q：免费吗？**
插件免费开源。OpenAI 接口需要你自己付费；Ollama 完全免费。

**Q：出问题了找谁？**
把控制台报错（Ctrl+Shift+I）和你的配置截图发出来，说明情况即可。
